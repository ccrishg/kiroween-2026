# Kiroween 2026 — checklist de entrega

Para la última semana. Cada casilla es un requisito del reglamento oficial. Lo
que no esté marcado el **jueves 3 de diciembre** es un riesgo de descalificación
o de puntos perdidos.

Deadline: **sábado 5 de diciembre, 07:00 KST**. Entrega objetivo: **miércoles 2
o jueves 3**.

---

## Bloqueantes — si falta uno, la entrega puede quedar descalificada

- [ ] El repo está en **GitHub** y es **público** (no GitLab, no Bitbucket)
- [ ] Hay un fichero de **licencia open source** y GitHub la detecta: se ve en
      la sección **"About"** de la portada del repo
- [ ] El directorio **`/.kiro` está en la raíz** y **tracked por git**
- [ ] **`.gitignore` no contiene `.kiro`** ni ninguna de sus subcarpetas
      → comprobar con: `git check-ignore -v .kiro` (no debe devolver nada)
- [ ] El repo contiene **todo** el código fuente, assets e instrucciones
      necesarias para que el proyecto funcione
- [ ] El proyecto **no contiene código preexistente sin declarar**. Todo el
      trabajo se hizo después del 31 de octubre de 2026 (01:00 KST)
- [ ] Si la categoría es **Skeleton Crew**: el repo tiene **2 carpetas
      separadas** para las 2 aplicaciones

## La app

- [ ] Hay una **URL pública** de la aplicación funcionando
- [ ] La app se ha probado **desde un navegador en limpio / incógnito**
- [ ] Las instrucciones del README se han seguido **desde un clon nuevo** y
      funcionan
- [ ] Si hace falta login, las **credenciales de prueba** están en el campo
      correspondiente del formulario de Devpost (ese campo no es público)
- [ ] El acceso es **gratis y sin restricciones** y seguirá activo hasta el
      **30 de enero de 2027, 06:00 KST** (fin del Judging Period)

## El vídeo

- [ ] Dura **menos de 3 minutos**
- [ ] Muestra el proyecto **funcionando** en el dispositivo para el que se
      construyó, de punta a punta
- [ ] Subido a **YouTube** y **público** (no "no listado" sin comprobar que el
      enlace abre desde sesión cerrada)
- [ ] **Sin música con copyright**, sin marcas registradas de terceros, sin
      material ajeno sin permiso
- [ ] El audio se entiende
- [ ] Comunica **qué problema resuelve, para quién y por qué importa**

## Los textos

- [ ] **Descripción** de features y funcionalidad
- [ ] **Write-up de cómo se usó Kiro**, cubriendo lo que aplique: superficies
      (IDE/CLI/Web/Crew), custom agents, hooks, spec-driven development,
      steering docs, MCP, property-based testing y powers — con ejemplos
      concretos y enlaces a ficheros del repo
- [ ] Todo el material **en inglés**
- [ ] README con pitch, stack, instrucciones y enlaces al vídeo y a la app

## El formulario de Devpost

- [ ] **Categoría** seleccionada: `Resurrection / Frankenstein / Skeleton Crew / Costume Contest`
- [ ] **Bonus prizes** seleccionados
- [ ] Equipo correcto (máximo 3) y **Representative** designado

### Best Student Project — de cada miembro del equipo

- [ ] Categoría indicada
- [ ] Confirmación de que **todos** somos estudiantes
- [ ] LinkedIn de cada miembro
- [ ] Email de estudiante de cada miembro
- [ ] Año y grado de cada miembro
- [ ] Nombre de la universidad de cada miembro
- [ ] Prueba de matrícula localizada y lista por si la piden

### Otros bonus

- [ ] **Blog:** URL del post público, publicado dentro del Submission Period,
      mencionando explícitamente que es parte del Kiroween 2026 hackathon
- [ ] **Social:** URL del post, con `#KiroweenHackathon26` **al principio** del
      texto, contando qué nos gusta de Kiro y cómo cambió nuestra forma de
      desarrollar
- [ ] **Kiro Crew App:** URL del repo público de la app + descripción de features
- [ ] **Ghost of Kiroween Past:** confirmado el registro en Kiroween 2025
- [ ] **Startup:** confirmación de fundador, LinkedIn y web de la startup

## Antes de pulsar enviar

- [ ] Borrador guardado y revisado por los dos
- [ ] Todos los enlaces abiertos en una ventana de incógnito y comprobados
- [ ] Último push hecho y la rama por defecto del repo es la que queremos que
      vean los jueces
- [ ] Fecha y hora de envío: ______ (objetivo: 2-3 de diciembre)
